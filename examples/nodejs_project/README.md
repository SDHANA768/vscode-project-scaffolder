## 🚀 Getting Started

### 1. Run the Backend
```cmd
npm install && npm run dev
```
Server: `http://localhost:3000`

### 2. Run the Frontend
```cmd
cd frontend
npm install
npm run dev
```

## 📦 Installing & Uninstalling Packages

Always use the wrappers — they auto-update `package.json`:

```cmd
npm_install.bat express axios
npm_uninstall.bat axios
```

For dev dependencies: `npm_install.bat jest --save-dev`

> ⚠️ Never use plain install commands — they won't update `package.json`!

## 🔧 VS Code Settings

Open `.vscode/settings.json` to toggle terminal mode:

```json
// Option 1 — Terminal always opens at ROOT (default)
"terminal.integrated.cwd": "${workspaceFolder}",

// Option 2 — Terminal follows current file folder
// "terminal.integrated.cwd": "${fileDirname}"
```
