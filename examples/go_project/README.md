## 🚀 Getting Started

### 1. Run the Backend
```cmd
go run cmd/main.go
```
Server: `http://localhost:8080`

### 2. Run the Frontend
```cmd
cd frontend
npm install
npm run dev
```

## 📦 Installing & Uninstalling Packages

Always use the wrappers — they auto-update `go.mod`:

```cmd
go_get.bat github.com/gin-gonic/gin
go_remove.bat github.com/gin-gonic/gin
```

Go uses full package paths e.g. `github.com/package/name`

> ⚠️ Never use plain install commands — they won't update `go.mod`!

## 🔧 VS Code Settings

Open `.vscode/settings.json` to toggle terminal mode:

```json
// Option 1 — Terminal always opens at ROOT (default)
"terminal.integrated.cwd": "${workspaceFolder}",

// Option 2 — Terminal follows current file folder
// "terminal.integrated.cwd": "${fileDirname}"
```
