## 🚀 Getting Started

### 1. Run the Backend
```cmd
php -S localhost:8000 public/index.php
```
Server: `http://localhost:8000`

### 2. Run the Frontend
```cmd
cd frontend
npm install
npm run dev
```

## 📦 Installing & Uninstalling Packages

Always use the wrappers — they auto-update `composer.json`:

```cmd
composer_install.bat guzzlehttp/guzzle
composer_uninstall.bat guzzlehttp/guzzle
```

Requires [Composer](https://getcomposer.org) installed.

> ⚠️ Never use plain install commands — they won't update `composer.json`!

## 🔧 VS Code Settings

Open `.vscode/settings.json` to toggle terminal mode:

```json
// Option 1 — Terminal always opens at ROOT (default)
"terminal.integrated.cwd": "${workspaceFolder}",

// Option 2 — Terminal follows current file folder
// "terminal.integrated.cwd": "${fileDirname}"
```
