## 🚀 Getting Started

### 1. Run the Backend
```cmd
uvicorn app.main:app --reload
```
Server: `http://localhost:8000`

### 2. Run the Frontend
```cmd
cd frontend
npm install
npm run dev
```

## 📦 Installing & Uninstalling Packages

Always use the wrappers — they auto-update `requirements.txt`:

```cmd
pip_install.bat requests numpy
pip_uninstall.bat numpy
```

Activate venv first:
```cmd
backend\\\\venv\\\\Scripts\\\\activate
```

> ⚠️ Never use plain install commands — they won't update `requirements.txt`!

## 🔧 VS Code Settings

Open `.vscode/settings.json` to toggle terminal mode:

```json
// Option 1 — Terminal always opens at ROOT (default)
"terminal.integrated.cwd": "${workspaceFolder}",

// Option 2 — Terminal follows current file folder
// "terminal.integrated.cwd": "${fileDirname}"
```
